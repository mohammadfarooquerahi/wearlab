## 📌 Overview

**WEARLAB** is a bespoke, minimalist, high-performance WordPress & WooCommerce theme designed specifically for modern direct-to-consumer (D2C) streetwear brands. Engineered with high-contrast typography, seamless mobile-first UX, and automated Cash on Delivery (COD) workflows for the Pakistani e-commerce market.

---

## 🚀 Key Features

* **Visual Live Customizer:** 100% client-editable homepage sections (Hero Banner, Shop by Fit cards, Featured Drops, Brand Statements, Customer Reviews, Announcement Ticker, and Newsletter) via **Appearance > Customize**.
* **Smart Content Fallback Engine:** Policy pages (`/shipping-policy/`, `/returns-policy/`, `/privacy-policy/`, `/terms-conditions/`) display custom text entered in WordPress Editor or automatically fall back to styled consumer guarantees.
* **Master Policies Hub:** All-in-one `/policies/` page with anchor-scroll tabs.
* **Variable Sizing (S, M, L, XL):** Optimized product variation switcher with real-time gallery sliders and PKR currency formatting.
* **Automated Order Dispatch & Email System:** Integrated with WooCommerce hooks (`woocommerce_thankyou`, `woocommerce_checkout_order_processed`) and configured for Hostinger Titan SMTP.
* **Floating WhatsApp Concierge:** Dynamic WhatsApp support widget located at the bottom-left corner with pre-filled greeting text.
* **Mobile-First Layout:** Ultra-fast loading, fully responsive drawer cart, and slide-out navigation.

## 🛠️ Installation & Setup

1. In WordPress Admin, navigate to **Appearance > Themes > Add New > Upload Theme**.
2. Upload `wearlab.zip` and click **Activate**.
3. Go to **Appearance > Customize** to configure brand settings, hero banner, announcement tickers, and WhatsApp concierge.
4. Refer to `WEARLAB_CLIENT_MANUAL.pdf` for complete step-by-step handover guidance.
